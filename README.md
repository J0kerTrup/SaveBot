# SaveBot

Telegram-бот-скачивалка. Отправляешь ссылку на TikTok, Instagram, YouTube или трек Spotify (в личке или в группе), и бот отвечает на это сообщение:

- видео (H.264, до 50 МБ) и отдельно трек в mp3 с названием и исполнителем;
- если видео нет (фото-пост с музыкой) — только трек;
- если видео больше 50 МБ — только трек: больше Telegram не даёт отправить боту через обычный Bot API.

YouTube: ролики, Shorts и music.youtube.com, до 720p. Ролик длиннее 10 минут приходит только звуком, длиннее часа и стримы — отказ.
Ссылки на каналы и плейлисты бот пропускает молча.

Spotify: только ссылки на треки (и spotify.link). Звук Spotify закрыт DRM, его бот не трогает: со страницы трека берёт
название, исполнителя, длительность и обложку, находит трек на YouTube (из первых 5 результатов — ближайший по длительности)
и присылает mp3 с обложкой.

Повторную ссылку бот не скачивает заново, а отдаёт уже загруженный файл (file_id). Ограничения: не больше 2 ссылок из одного
сообщения, 6 ссылок в минуту на чат и 3 скачивания одновременно.

## Запуск

1. В @BotFather: `/newbot` → токен. Затем **`/setprivacy` → Disable**, иначе в группах бот не видит обычные сообщения
   со ссылками. Если бот уже был в группе, удали его и добавь заново, чтобы настройка применилась (или сделай его админом).
2. `cp .env.example .env`, вписать `BOT_TOKEN`.
3. `docker compose up -d --build`.

Локально: нужен `ffmpeg` в PATH, затем `uv sync` и `BOT_TOKEN=... uv run python bot.py`.

## Языки и профиль

`/start` (и `/lang`) показывает меню: кнопка «Добавить в чат» и флажки шести языков (ru, uk, en, es, pt, tr). В личке язык
меняет человек, в группе — только админы. Пока язык не выбран, бот говорит на языке Telegram пользователя. Выбор хранится в
`data/savebot.sqlite3`.

Имя, описания и команды на всех языках — в `i18n.py` (`PROFILE`, `COMMANDS`). После правки текстов:
`docker compose -p savebot exec savebot /app/.venv/bin/python setup_profile.py`. Имя бота Telegram разрешает менять редко.

## Instagram

Без входа Instagram часто отдаёт пустой ответ. Тогда выгрузи cookies.txt (формат Netscape) из браузера, где выполнен
вход в **отдельный** аккаунт, положи его в `data/cookies.txt` и пропиши `COOKIES_FILE=/data/cookies.txt`. Закрытые посты бот не скачивает.

## Обновление yt-dlp

Площадки часто меняют API — обновляй yt-dlp: `uv lock --upgrade-package yt-dlp`, затем пересобери образ.
